Process Flow
FROM RAW LOG
TO LIVE ALERT
Five-stage behavioral analysis pipeline — raw logs become scored risk and actionable alerts in under 2 seconds.
01
Log Collection
Every login, file access, download and command event is captured into activity logs with timestamp, IP address, and resource metadata.
02
Feature Extraction
Raw events become 7 numerical features: access ratio, failed logins, off-hours count, bulk operations, suspicious events, unknown IPs.
03
Isolation Forest ML
Unsupervised model builds 100 random isolation trees to find statistical outliers — users whose behavior deviates from the org norm.
04
Dynamic Risk Scoring
Anomaly confidence + contextual bonuses → 0–100 risk score updated each cycle. Thresholds: LOW <35, MEDIUM 35–65, HIGH >65.
05
XAI Alert + PDF Report
Admin receives a typed alert with explainable AI breakdown — which behavioral factors drove the flag and recommended actions.
